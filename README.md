# 🎮 Tic-Tac-Toe with MCTS AI 🤖

## Overview
This is a Tic-Tac-Toe game featuring an AI opponent based on Monte Carlo Tree Search (MCTS). The game is built using Python and PyQt5 for the graphical user interface (GUI). In the future, we plan to enhance the AI by implementing AlphaZero for improved gameplay. 🚀

## Features ✨
- **🎨 GUI with PyQt5:** An interactive interface for playing Tic-Tac-Toe.
- **🧠 MCTS AI:** AI opponent that uses Monte Carlo Tree Search for decision-making.
- **👤 Player vs AI:** Play against an AI that improves its decision-making through simulations.
- **🌈 Colorful UI:** Improved visual appearance with colored buttons and labels.

## Installation 🔧
Ensure you have Python installed, then install the required dependencies:
```sh
pip install numpy PyQt5
```

## How to Run ▶️
Run the following command in your terminal or command prompt:
```sh
python  main.py
```
